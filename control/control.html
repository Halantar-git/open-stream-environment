Сцены
Каждая сцена — отдельный источник в OBS, показывается вместо игры целиком (не поверх).
Свойства сцены

Twitch

Чат подключается анонимно и не требует токена. Для алертов о фоллоу/сабах/чирах нужно зарегистрировать приложение и авторизоваться.

Redirect URI для приложения:
Чат Алерты

DonationAlerts

Донаты автоматически увеличивают счётчик цели и запускают алерт.

Redirect URI для приложения:
DonationAlerts

YouTube

Чат и события прямого эфира (Super Chat, новые участники) через YouTube Data API.

Redirect URI для приложения:
YouTube

OBS WebSocket

Подключение к OBS WebSocket (OBS 28+, Tools → WebSocket Server Settings) для переключения сцен пультом.

Маппинг сцен: логическое имя пульта → имя сцены в OBS.

Кастомные OBS команды (RAW Requests, obs-websocket v5).

Ракурсы Камер (Мультикамера)

Перманентная смена активной камеры за баллы Twitch или вручную (без таймера).

Эффекты и Фильтры Камеры

Включение фильтров OBS (Ч/Б, размытие, пикселизация, хромакей) за баллы Twitch или вручную. Длительность 0 — вкл/выкл тумблером.

OBS

Soundboard (Шумотека)

Запуск звуков и анимаций за баллы канала Twitch: награда → аудиофайл + картинка/GIF.

Stream Deck

Свои иконки для кнопок плагина Elgato Stream Deck. Файл (PNG/JPG/GIF/WebP) копируется в media/ и применяется поверх стандартной иконки плагина.

Оформление

Тема влияет только на сам оверлей (и его превью на канвасе) — панель управления всегда выглядит одинаково.

Экспорт / импорт настроек

Экспорт сохраняет полный config.json — раскладку, темы, цель, а также токены и ключи Twitch/DonationAlerts. Файл содержит секреты — не выкладывайте его публично.
