# Аудио для Колеса Фортуны

Звуковые файлы для Колеса Фортуны (лежат здесь, отдаются оверлею локальным
сервером по пути `/assets/audio/...`):

- `wheel-spin.mp3` — звук вращения барабана (roulettevision), ~5.3 с. Проигрывается
  один раз за цикл; длительность вращения колеса подогнана под него.
- `win.wav` — джингл победы (littlerobotsoundfactory), ~2.6 с.
- `elimination.wav` — джингл выбывания («проигрыш»), ~2.9 с.

Если файл отсутствует или не декодируется, оверлей автоматически использует
встроенные Web Audio-звуки (сгенерированные осцилляторами), поэтому приложение
продолжает работать без них.
