# Аудио для Колеса Фортуны

Положите сюда оригинальные звуковые файлы и замените заглушки:

- `wheel-spin.mp3` — циклический звук вращения барабана (стиль «Поля Чудес»).
- `win.mp3` — фанфары/звук победы.
- `elimination.mp3` — короткий звук выбывания («вылет»).

Файлы отдаются оверлею локальным сервером по пути `/assets/audio/...`.
Если файл отсутствует или не декодируется, оверлей автоматически использует
встроенные Web Audio-звуки (сгенерированные осцилляторами), поэтому приложение
продолжает работать без них.
