# {{name}}

Пакет темы для Open Stream Environment.

## Что внутри

- `theme.json` — манифест и токены темы (`--md-*`, шрифты, панели).
- `theme.css` — необязательные правила под `[data-theme="plugin:{{id}}"]`.

## Установка

Скопируйте папку `{{id}}` в каталог пакетов и перезапустите приложение:

- разработка (`npm run tauri:dev`) — `config/plugins/` в корне репозитория;
- установленное приложение — каталог данных `com.openstreamenvironment.app`
  (Windows: `%APPDATA%\com.openstreamenvironment.app\plugins\`).

Тема появится в «Настройки → Оформление» с пометкой пакета. Редактировать и
удалять её из панели нельзя — источник правды лежит в папке пакета.

## Проверка

```sh
npx ose-plugin check .
```

В репозитории OSE — `node sdk/validate.mjs .`.

## Шрифты и картинки

Шрифт попадает в эфир, поэтому берите только свободные лицензии (SIL OFL и
подобные) и кладите текст лицензии рядом с файлом. Чужие логотипы и картинки без
явной лицензии в тему не берите.
