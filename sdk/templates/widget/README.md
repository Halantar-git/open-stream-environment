# {{name}}

Пакет виджета для Open Stream Environment.

## Что внутри

- `widget.json` — манифест: id, схема настроек, геометрия по умолчанию.
- `widget.js` — код виджета, регистрируется через `OSE.defineWidget`.
- `widget.css` — стили, ограниченные `data-type="plugin:{{id}}"`.

## Установка

Скопируйте папку `{{id}}` в каталог пакетов — перезапуск приложения не нужен:
панель сама перезагрузится, когда вернёте ей фокус, а источник в OBS обновите
вручную:

- разработка (`npm run tauri:dev`) — `config/plugins/` в корне репозитория;
- установленное приложение — каталог данных `com.openstreamenvironment.app`
  (Windows: `%APPDATA%\com.openstreamenvironment.app\plugins\`).

После обновления страницы виджет появится в колонке виджетов под своим именем.

## Проверка

```sh
npx ose-plugin check .
```

В репозитории OSE то же самое делает `node sdk/validate.mjs .`; для всех
пакетов сразу — `npx ose-plugin check config/plugins`.
