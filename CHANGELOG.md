# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`,
где PATCH — исправления, MINOR — новая функциональность без слома
совместимости, MAJOR — несовместимые изменения (пока не было).

## [Unreleased]

## [2.5.2] — 2026-09-05

### Added
- Отправка сообщений в чат Twitch из плавающего окна «Чат» и Web Remote:
  поле ввода с кнопкой «Отправить», подтверждение через Twitch Helix
  (`POST /helix/chat/messages`, скоуп `user:write:chat`) с авто-рефрешем
  токена, оптимистичный показ сообщения до подтверждения и ограничение
  частоты отправки (не чаще одного сообщения в ~1.6 секунды).
- Всплывающие уведомления в панели управления о новых событиях: фоллоу,
  подписка, гифт-подписка, чир и донат. Появляются в правом верхнем углу
  и автоматически исчезают через несколько секунд.
- Нативные OS-уведомления (Electron) о тех же событиях, когда панель
  управления свёрнута в трей, скрыта или находится не в фокусе.
- Звуковой сигнал при уведомлениях (файл `assets/audio/buzzer.wav`) с
  переключателем и настройкой громкости в «Настройки → Приложение».

## [2.5.1] — 2026-09-05

### Added
- Заставки между сценами: на каждой сцене (Начало / BRB / Разговор / Окончание /
  Колесо / Голосование) можно задать видео, картинку или GIF, который
  проигрывается при переходе между игрой и сценой (Start → Main, → BRB,
  → Talk, → End, → Wheel, → Poll). Видео переключается по окончанию,
  картинка/GIF — по таймеру; без файла показывается стандартная заставка.
- Отдельная вкладка «Заставки» в основном меню: общая заставка для всех сцен
  плюс настройка файла и длительности отдельно для каждой сцены.
- Длительность заставки — выпадающий список «авто» + 1–30 сек (для
  картинки/GIF; видео всегда проигрывается до конца).
- Новая OBS-сцена заставки: поле `Opening` в «Настройки → OBS WebSocket»
  маппит сцену, где лежит браузерный источник `/overlay/video-splash.html`.
- Stream Deck: добавлены сцены `Main` и `Poll`.

### Changed
- Тема «Material You» переведена на фирменную синюю палитру приложения
  (синий `#005faf` / стальной `#386595` на тёмном `#111318`).
- 3D-сфера Material You переведена на алерт-управление (как куб Pixel Perfect):
  скрыта до первого алерта, иконка алерта вращается на сфере, донат даёт
  «прыжок»; размер уменьшен, чтобы края не обрезались.
- Web Remote: `Main` перенесён сразу после «Начало стрима», кнопки сцен
  подкрашены по важности (Main — акцент, Start — зелёная, End — красная).

## [2.5.0] — 2026-09-05

### Added
- Live-переключение порта сервера: смена порта на вкладке
  «Настройки → Приложение» теперь применяется сразу, без перезапуска.
  Панель управления сама переподключается к новому порту; при неудачной смене
  (порт занят) сервер откатывается на прежний порт, а панель автоматически
  восстанавливает соединение.
- Выбор соотношения сторон канваса в тулбаре редактора (16:9, 16:10, 21:9,
  32:9, 4:3, 1:1, 9:16, 3:4). Канвас подстраивается под выбранную пропорцию;
  раскладка остаётся процентной, поэтому оверлей корректно работает на
  ультрашироких и вертикальных (Shorts/TikTok Live) источниках OBS.
- Голосование в чате: отдельная полноэкранная сцена с живой диаграммой
  (столбики или круг). Зрители голосуют командой (`!poll 1`, `!poll 2`, …);
  пункты, команда и тип диаграммы настраиваются в отдельной панели
  «Голосование» (кнопка в шапке). Один голос на зрителя — повторный голос
  заменяет прежний.
- Тест голосования в панели отладки (генерирует тестовые голоса по пунктам).
- Расширенный редактор «своей темы»: гранулярные переопределения шрифтов,
  рамок и свечения (цвет + интенсивность) поверх пресетов.
- «Свой CSS» для тем: лёгкий редактор с подсветкой синтаксиса, автодополнением
  (свойства, значения, `var(--…)`, селекторы) и проверкой синтаксиса, в
  отдельном окне по кнопке. Изменения синхронизируются с превью на лету.
- Живое превью черновика темы в отдельном окне (кнопка «Превью в окне»).
- Дублирование пользовательской темы и сброс переопределений к авто.
- Больше форм панелей для «своей темы»: скруглённая, угловатая (HUD), острая,
  мягкая, капсула, скобки (4 угла) и Hazard.
- Экспорт и импорт пользовательских тем в отдельный JSON-файл.
- CSS-редактор стал ближе к Notepad++: панель инструментов (отмена/повтор,
  выделить всё, очистить, копировать), поиск и замена (по одному / все), строка
  состояния со строкой/столбцом и количеством символов.
- Полноценный редактор темы в отдельном окне: кнопки «Создать свою тему» и
  «Изменить» открывают окно со всеми настройками (цвета, форма, шрифты, рамки,
  свечение, свой CSS), а из панели настройки убраны.
- Расширены «No-Code» настройки темы: цвет фона и текста, стиль рамки
  (solid/dashed/dotted/double), прозрачность панелей и размытие фона.
- Окно «Сэмплы» — набор тестовых карточек (алерт, чат, цель, голосование) для
  оценки темы вживую.

### Changed
- Декоративные 3D-виджеты (вывески, радар, щит, сфера, куб) получили роль и
  теперь следуют за сменой темы: при переключении они заменяются аналогом
  активной темы (вывеска → вывеска, радар → радар), а если аналога нет —
  скрываются на оверлее и помечаются «выкл» в списке слоёв.
- Канвас редактора: виджеты, не относящиеся к активной теме, больше не
  отображаются (раньше подсвечивались «выкл»).
- Шрифты темы Pixel Perfect: убран пиксельный Tiny5 — данные/цифры (таймеры,
  суммы, счётчик голосов) теперь тем же PT Sans Caption, что и основной текст.
- Куб Pixel Perfect: убрана реакция на чат; куб скрыт, пока нет активного
  алерта, и появляется при первом алерте (аналогично подложке алертов).
- Куб Pixel Perfect: иконки алертов ставятся в очередь и показываются по
  одной, а не затирают друг друга.

### Fixed
- Иконка приложения в системном трее снова отображается (исправлен путь к
  иконке: использовался несуществующий `assets/icons/icon.png`).

## [2.4.1] — 2026-08-30

### Added
- Куб Pixel Perfect: иконка активного алерта (follow/sub/донат и т.д.)
  отображается на всех шести гранях куба и вращается вместе с ним.
- Вывеска Elite (3D-тема Cobra Mk II): анимированная неоновая вывеска с
  эмблемой Elite Dangerous — оранжевое неоновое свечение, мерцание, покачивание
  и глитч на чат/донат, с настройкой перспективы (по аналогии с вывеской
  Grim HEX).

### Changed
- Куб Pixel Perfect переделан в прозрачный каркасный: только рёбра толщиной
  1–2px с затуханием по глубине (без заливки граней).
- Шрифты темы Pixel Perfect: PT Sans Caption (текст/заголовки) + Tiny5
  (данные/цифры) с кириллицей; чат остался на Roboto Condensed для читаемости.
- Донат-цель Pixel Perfect: сумма «0/5000» теперь тем же шрифтом PT Sans
  Caption, что и заголовок цели (раньше — пиксельный Tiny5).
- 3D-виджеты Star Citizen переименованы в Grim HEX: файлы, классы и подписи
  чата, донат-цели, голо-алерта и радара теперь носят имя Grim HEX.

### Fixed
- Алерты Material You и Pixel Perfect больше не оставляют пустую панель на
  стриме — подложка скрыта, пока нет активного алерта.
- Куб Pixel Perfect больше не выходит за границы виджета (размер скорректирован
  под изометрическую проекцию).
- Донат-цель Material You (3D): скруглённая подсветка прогресс-бара больше не
  срезается по краям.
- Вывеска Elite (3D-тема Cobra Mk II): на канвасе редактора и в списке слоёв
  помечается как неактивная при переключении на другую тему.

## [2.4.0] — 2026-08-29

### Added
- Иконки виджетов на канвасе редактора (рядом с подписью при наведении/выборе).
- Озвучка обычных донатов голосом DonationAlerts (если сервис отдаёт ссылку) —
  отдельный переключатель в Настройках.
- В «Свой виджет» добавлен режим «Встраивание (iframe)» — ссылка на внешний
  браузер-источник (например, виджет ЯП! от DonationAlerts).
- «Чат поверх игры» — прозрачное плавающее окно чата поверх игры
  (Borderless Window, клики проходят насквозь) для одномониторных стримов:
  включается кнопкой в Настройках или глобальным хоткеем (по умолчанию
  Control+Shift+L). В настройках — монитор, размер, положение, прозрачность
  фона и размер шрифта.
- 3D-виджеты для темы Material You (тумблер «3D»): мягкая сфера с орбитой,
  чат на приподнятой карточке, градиентная донат-цель и всплывающий алерт с
  вращающимся значком.
- 3D-виджеты для темы Pixel Perfect (тумблер «3D»): вращающийся изометрический
  пиксель-куб, пиксельный чат, блочная шкала донат-цели и пиксельный алерт.

### Changed
- Сборка: иконки приложения разведены по платформам — Windows использует
  `icon.ico`, macOS — `icon.icns`, Linux — набор PNG из `assets/icons/`.
- Темы: 2D/3D-группы объединены в «семьи» — у каждой темы свой тумблер «3D»
  (Orbital → Star Citizen, Elite → Cobra Mk II, Nuclear → свои CRT-виджеты).
- 3D-фишки: у активной 3D-темы можно отдельно включать/выключать каждый
  3D-виджет (свой тумблер на каждый).
- Автозамена 2D → 3D: при включённом 3D виджеты ролей «чат/цель/алерты»
  заменяются 3D-аналогами активной темы, сохраняя позицию и размер; при
  выключении 3D возвращаются к 2D-виду.
- Перенос 3D-виджетов между темами: явно расставленный 3D-чат/цель/алерт
  следует за сменой темы (Material You → Star Citizen → Pixel Perfect → ...).
- Редактор следует теме: на канвасе, в слоях и в панели свойств виджеты
  показываются в эффективном виде (имя, иконка, превью, нужные настройки).

### Fixed
- Перетаскивание/ресайз виджета больше не «отскакивает» на прежнее место при
  фоновом обновлении канваса.
- Список слоёв обновляется при переключении темы и включении/выключении 3D.
- У 3D-чата снова видна настройка «Перспектива», в том числе у 2D-чата,
  авто-подменённого на 3D.

## [2.3.1] — 2026-08-21

### Added
- Пресеты раскладки: сохранение текущего расположения виджетов под именем,
  загрузка и удаление пресетов прямо из тулбара редактора. Вместе с раскладкой

### Changed

  и добавляет 3D-виджеты. В группе 3D появился вариант «Выкл». При первом
  запуске старый `activeThemeId` мигрирует автоматически.

  **Replay** (повторный показ алерта в оверлее без дублирования записи).
- **Колесо Фортуны** — проведение розыгрышей: команда участия, сбор
  участников из чата, счётчик участников в реальном времени, перемешивание
  (Фишера-Йетса), генерация секторов колеса и режим на выбывание.
- Псевдо-3D визуал Колеса Фортуны: CSS 3D-трансформы (`perspective`/`rotateX`),
  глянцевые градиенты секторов, объёмные тени и анимированный 3D-маркер;
  колесо адаптируется под активную тему.
- Сбор участников через чат: при активном сборе ники зрителей, написавших
  команду, добавляются в `Set` — один зритель = один шанс.
- Ручное управление участниками в админке: добавление никнейма вручную (с
  защитой от дублей) и удаление отдельных зрителей кнопкой-крестиком.
- Вывод списка участников на экран стрима — виджет `overlay-participants-list`
  показывает счётчик и первые N никнеймов в реальном времени.
- Стрим-алерты розыгрыша: анимированный алерт «Сбор начался» при старте и
  крупный алерт «Победитель: …» с фанфарами при остановке колеса.

### Fixed
- **DonationAlerts**: стабилизировано Centrifugo WebSocket-подключение —
  авто-реконнект с бэкоффом, heartbeat (ping/pong watchdog) и автоматическое
  обновление `access_token` через `refresh_token`.
- **Twitch EventSub**: добавлены keepalive-watchdog, авто-refresh токена и
  исправлен двойной реконнект при `session_reconnect`.
- Детальное логирование событий подключения/ошибок для интеграций.

### Changed
- **Оптимизация Electron**: ограничение FPS для фоновых окон,
  `backgroundThrottling`/`spellcheck` и очистка ресурсов при выходе.
- Раскладка оверлея перенесена в локальную БД (единый источник истины),
  из `config.json` убрано дублирование.
- Токены авторизации больше не хранятся в открытом виде в `config.json`.

### Security
- **Безопасное хранилище ключей**: секреты Twitch/DonationAlerts шифруются
  через Electron `safeStorage` (DPAPI/Keychain/libsecret) перед записью на диск.

## [1.7.0] — 2026-08-09

### Added
- Отдельное окно **«Чат»** — читаемый лог сообщений Twitch-чата (без
  прозрачных карточек оверлея), чтобы следить за чатом во время стрима, не
  переключаясь в браузер. Открывается кнопкой в топбаре панели управления.
  Только чтение — отправка сообщений не поддерживается (чат подключён
  анонимно). Не хранит историю: показывает сообщения, пришедшие пока окно
  открыто, как и виджет чата на оверлее.
- Всплывающее окно **редактора кода** для «Своего виджета» — вкладки
  HTML / CSS / JS с живым превью (обновляется на лету при вводе) и кнопкой
  «Сохранить». Открывается кнопкой «Редактировать код» в панели свойств,
  когда у виджета выбран режим «Свой HTML».

### Fixed
- **JS в «Своём виджете» теперь реально выполняется.** Раньше произвольный
  HTML вставлялся через `innerHTML`, из-за чего вложенные `<script>` тихо
  не срабатывали (стандартное поведение браузеров). Рендер переведён на
  `<iframe>` с полноценным HTML-документом (свой `<style>` и `<script>`),
  так что таймеры, анимации и любой код в виджете работают по-настоящему —
  и в превью редактора, и на настоящем оверлее.
