# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/): `MAJOR.MINOR.PATCH`,
где PATCH — исправления, MINOR — новая функциональность без слома
совместимости, MAJOR — несовместимые изменения (пока не было).

## [2.3.1] — 2026-08-21

### Added
- Пресеты раскладки: сохранение текущего расположения виджетов под именем,
  загрузка и удаление пресетов прямо из тулбара редактора. Вместе с раскладкой
  пресет сохраняет активные 2D/3D-темы, чтобы 3D-виджеты возвращались вместе с
  пресетом.

### Changed
- Настройки активных тем 2D и 3D теперь хранятся в отдельных полях конфига
  (`appearance.activeThemeId2d` и `appearance.activeThemeId3d`): 2D-тема задаёт
  базовую палитру оверлея, а включённая 3D-тема (Star Citizen) перекрывает её
  и добавляет 3D-виджеты. В группе 3D появился вариант «Выкл». При первом
  запуске старый `activeThemeId` мигрирует автоматически.

## [2.3.0] — 2026-08-21

### Added
- Вывеска Café Musain — анимированная неоновая вывеска (14 сегментов, янтарь
  с розовым/синим/оранжевым акцентами) для темы Star Citizen.

### Changed
- Все шрифты переведены на SIL OFL: Roboto → Manrope, Roboto Mono →
  JetBrains Mono; из загрузки Google Fonts убраны неиспользуемые шрифты.
- Фон виджетов Star Citizen (цель, чат, голо-алерт) приведён к стилю
  «Последние события»: панель + сканлайны + уголки-скобки.
- Вывеске Grim HEX добавлен наклон-перспектива (настройка в инспекторе).

### Removed
- Удалены все встроенные темы, кроме Material You, Orbital, Pixel Perfect
  и Star Citizen (удалены Levski и темы производителей кораблей).

### Fixed
- Исправлен шрифт суммы в Star Citizen goal-баре (вложенные кавычки ломали
  inline-стиль, из-за чего Orbitron не применялся).

## [2.2.1] — 2026-08-16

### Changed
- Тема «Grim HEX» переработана с кричащих неонов (зелёный/розовый/фиолетовый)
  на приглушённую «терминальную» гамму: тревожный красный неон `#FF1800` как
  главный акцент, грязный янтарь `#F97316` для предупреждений, тёмный
  астероидный металл и острые углы (radius 0).

## [2.2.0] — 2026-08-16

### Added
- Тема «Grim HEX» в блоке Star Citizen — киберпанк-подполье: астероидный
  сланец + сталь, неон (зелёный/розовый/фиолетовый), грязное золото для
  hazard-полос.
- Тема «Levski» в блоке Star Citizen — советский конструктивизм: базальт,
  пыль Деламара, кумач, янтарь и гидропонная зелень.
- Шрифты Wallpoet (Grim HEX) и Pixelify Sans (Pixel Perfect, с кириллицей) в
  загрузку Google Fonts.
- Живой чат стрима на Web Remote: отдельная вкладка «Чат» с лентой сообщений
  Twitch/YouTube, автоскроллом и подсветкой ника/бейджей.

### Changed
- Все темы производителей Star Citizen переведены с «корпусного» вида на
  интерфейс кабины (HUD/MFD): цвета акцентов, шрифты и тёмное «стекло кабины»
  с оттенком цвета HUD приведены к референсам интерфейсов кораблей.
- Grey's Market получил пиратскую HUD-палитру (грязный янтарь, кроваво-красный,
  глитчевый белый).
- Consolidated Outland — неоновый HUD (циан + маджента).
- Тема Pixel Perfect: аркадные пиксельные шрифты (Silkscreen/Press Start 2P)
  заменены на чистый сжатый Rajdhani + пиксельный Pixelify Sans (основной
  шрифт темы и виджетов) с кириллицей.

### Fixed
- Размеры текста виджетов Pixel Perfect зафиксированы по пиксельной сетке
  (12/16/24/32px), чтобы цифры не «мылились».

## [2.1.0] — 2026-08-16

### Added
- Встроенный поиск по тексту в панели терминала (фильтр по содержимому строк).
- Полная локализация сообщений CLI-консоли (русский/английский) через
  `shared/locales` и `shared/i18n`.
- Экспорт/импорт медиафайлов: конфиг теперь упаковывает содержимое `media/`
  (звуки/картинки/GIF) в один JSON, импорт автоматически восстанавливает файлы.
- Команда терминала `media list | cleanup` — просмотр и удаление неиспользуемых
  медиафайлов.
- Файловое логирование сервера: `config/logs/ose-YYYY-MM-DD.log` с суточной
  ротацией и автоочисткой старше 7 дней.
- Запоминание размеров и позиций окон панели управления и чата между сессиями
  (`config/window-state.json`) с защитой от «окна за экраном».
- Общий модуль `server/token-refresh.js` для обновления OAuth-токенов с
  дедупликацией конкурентных вызовов.
- Тесты: `token-refresh`, `media`, `replaceConfig`, английская локализация CLI.

### Changed
- Зависимость `lowdb` (v1) удалена — `server/db.js` переписан на лёгкое
  синхронное JSON-хранилище `config/local-db.json` (схема и API сохранены).
- OAuth-токены теперь сохраняют время протухания `expiresAt` в config.json —
  при холодном старте не выполняется лишний refresh.
- `donationalerts.js`: `subscribe()` получает токен через `ensureAccessToken()`
  и повторяет запрос при `401`.

### Fixed
- Импорт конфига больше не теряет секции `soundboard` и `streamdeck`; добавлена
  валидация порта (1024–65535) и корректности массивов.

## [1.9.8] — 2026-08-16

### Added
- Web Remote / Stream Deck: мобильный веб-пульт (`/remote`) для управления
  оверлеем по локальной сети — переключение сцен, Колесо Фортуны, счётчик
  смертей, тестовые алерты и быстрая смена темы. Адрес пульта показывается в
  шапке панели управления и логируется при старте сервера.
- Расширенные настройки Колеса Фортуны прямо на Web Remote: команда
  розыгрыша, режим выбывания, настройки виджета участников (количество имён,
  размер/цвет текста, прозрачность фона, бегущая строка), громкость музыки и
  скорость вращения.
- Интеграция OBS WebSocket (obs-websocket v5, OBS 28+): переключение сцен OBS
  командами пульта (`SetCurrentProgramScene`), статус подключения и настройки
  (host/порт/пароль/маппинг имён сцен) в панели управления.
- Кастомные OBS команды (RAW Requests) с UI в панели управления и кнопками на
  Web Remote.
- Soundboard (Шумотека): запуск звуков и анимаций за баллы канала Twitch
  (channel points), маппинг наград на аудио/картинки с диска, громкость и
  режим очереди, тест из панели управления.
- Плагин Elgato Stream Deck (`streamdeck-plugin/`): сцены, Soundboard,
  счётчик смертей и Колесо Фортуны; двусторонняя синхронизация с сервером.
- Настройки Stream Deck в панели управления со своими иконками для экшенов.

### Fixed
- Пользовательские аудио/картинки Soundboard и иконки Stream Deck теперь
  сохраняются в каталог данных приложения (`media/`) и раздаются сервером, а
  не пишутся внутрь app.asar/папки установки.

### Changed
- Локализация дополнена блоками OBS, Soundboard, Stream Deck и Web Remote.

### Security
- Пароль OBS WebSocket теперь шифруется в config.json через Electron
  safeStorage (аналогично OAuth-токенам Twitch/DonationAlerts/YouTube).

## [1.9.4] — 2026-08-15

### Changed
- Отключено сохранение логов чата в lowdb (`appendChat` больше не пишет на
  диск) для оптимизации производительности при активном чате; сообщения
  по-прежнему доставляются в реальном времени по WebSocket.

### Fixed
- Розыгрыш: финальный победитель в режиме выбывания теперь определяется до
  удаления победителя из списка участников (`isFinalWinner`).
- Колесо Фортуны: добавлена блокировка `isSpinning` против race condition при
  авто-вращении — повторные команды выбора победителя игнорируются до
  завершения текущего цикла.
- Twitch EventSub: при `session_reconnect` повторная подписка больше не
  выполняется (Twitch сохраняет подписки), что убирает ошибку `409 Conflict`.

## [1.9.3] — 2026-08-15

### Added
- Система структурированного логирования `terminal_log`
  (`{ timestamp, service, level, message, data }`) с трансляцией через шину
  EventBus/WebSocket из сервисов (Twitch, DonationAlerts, сервер).
- Встроенный терминал логов в панели управления: вызов кнопкой «Логи» в шапке,
  тёмная выезжающая панель, подсветка уровней и сервисов, автоскролл (пауза при

### Fixed
- DonationAlerts / Centrifugo: исправлена ошибка `3003 (Bad Request)` при
  подключении — кадры connect/subscribe переведены на формат Centrifugo v2
  (`params`/`method`) с разделением строк `\n` (JSON-lines), усилена валидация
  `socket_connection_token`.
- DonationAlerts: устранена утечка памяти и дублирование WebSocket-слушателей —
  ссылка на сокет обнуляется (`ws = null`) при закрытии соединения.

## [1.9.2] — 2026-08-14

### Added
- Новая встроенная тема **Pixel Perfect**: минималистичный тёмный интерфейс в
  духе ShestakUI — почти чёрные нейтральные поверхности, плоские 1px рамки,
  приглушённый золотой акцент и шрифты Rajdhani / Roboto / Roboto Mono.
- Полная локализация интерфейса (русский/английский): словари `shared/locales/`,
  хелпер `shared/i18n.js`, переключатель языка в настройках, сохранение выбора
  в lowdb и мгновенная трансляция во все окна (панель управления, оверлей,
  сцены, Колесо Фортуны) через шину WebSocket + IPC `app:change-language`.
- Виджет «Визуализатор микрофона» (`overlay-audio-visualizer`): захват звука через
  `getUserMedia` + Web Audio API, отрисовка живой звуковой волны на Canvas при
  ~60 FPS (в тишине — плавная горизонтальная линия), настройки чувствительности,
  толщины линии, цвета и прозрачности в lowdb, фейковая волна в превью редактора.
- Три режима визуализации для виджета микрофона: «Плавная синусоида»,
  «Частотные столбики» (спектральный эквалайзер) и «Круговой визуализатор»
  (кольцо/обводка). Выбор режима (`visualizer_mode`) сохраняется в lowdb; для
  столбиков добавлены настройки количества полос (10–64) и расстояния между ними.
- Сборка для Windows: NSIS-установщик и портативный exe (electron-builder),
  настройки и локальная БД пишутся в записываемый каталог, а не внутрь asar.
- Подтверждение при закрытии приложения: диалог «Выйти / Отмена» (RU/EN).

### Changed
- На сцене Колеса Фортуны добавлен тот же фоновый слой, что и у остальных
  сцен: непрозрачная подложка активной темы и плавающие цветные пятна (для
  HUD-тем — фоновая сетка).

### Fixed
- Стрим-чат: закрепление «поверх всех окон» больше не сбрасывается при выходе
  из игрового режима; состояние кнопки 📌 синхронизируется с хоткеем
  `Ctrl+Shift+C` и переключателем в окне чата.
- Версия `lowdb` приведена к `^1.0.0` в соответствии с CommonJS API
  `server/db.js` (прежний `^3.0.0` ломал `require`).

- Сцена «Колесо Фортуны» в разделе «Сцены»: отдельный полноэкранный URL,

  виджет алертов/событий вместо отдельного оверлей-алерта: события идут через
  существующую шину `ALERT` и общую очередь виджета.
- Добавлена адаптивность интерфейса: относительные единицы (`rem`/`clamp`),
  медиа-запросы для панели управления и автоматическое масштабирование 3D
  Колеса Фортуны через `transform: scale()` при изменении размеров окна.
- В режиме на выбывание колесо автоматически продолжает вращение после
  вылета участника (с задержкой), пока не останется финальный победитель.

### Fixed
- Исправлена логика алерта `wheel_winner` в режиме выбывания: при выбывании
  выводится «❌ Выбыл из игры: [Имя]» и проигрывается `elimination.mp3`, а не
  фанфары. Когда остаётся последний участник, бэкенд принудительно ставит
  `isElimination: false` и отправляет «🎉 Главный Победитель Розыгрыша: [Имя]!».
- Убран дублирующий текст «Победитель» из кикера алерт-карточки: кикер
  `wheel_winner` теперь нейтральный («Колесо Фортуны»), а конкретный статус
  выводится только в заголовке.
- Виджет «Участники розыгрыша» теперь перерисовывает свой контент при каждой
  реконсиляции layout в оверлее, поэтому после добавления/перетаскивания он
  всегда синхронизирован с актуальным списком участников.

## [1.8.0] — 2026-08-12

### Added
- **Локальная БД** (`lowdb`) для сохранения данных между сессиями: раскладка
  оверлея, сессии стрима и история чата. Инициализация в `main.js`, IPC-каналы
  для чтения/записи.
- **История входящих событий** (`stream_events`) — донаты, подписки, фоллоу
  и чиры сохраняются в БД; панель «История событий» с пагинацией и кнопкой
  **Replay** (повторный показ алерта в оверлее без дублирования записи).
- **Колесо Фортуны** — проведение розыгрышей: команда участия, сбор
  участников из чата, счётчик участников в реальном времени, перемешивание
  (Фишера-Йетса), генерация секторов колеса и режим на выбывание.
- Псевдо-3D визуал Колеса Фортуны: CSS 3D-трансформы (`perspective`/`rotateX`),
  глянцевые градиенты секторов, объёмные тени и анимированный 3D-маркер;
  колесо адаптируется под активную тему.
- Сбор участников через чат: при активном сборе ники зрителей, написавших
  команду, добавляются в `Set` — один зритель = один шанс.
- Ручное управление участниками в админке: добавление никнейма вручную (с
  защитой от дублей) и удаление отдельных зрителей кнопкой-крестиком.
- Вывод списка участников на экран стрима — виджет `overlay-participants-list`
  показывает счётчик и первые N никнеймов в реальном времени.
- Стрим-алерты розыгрыша: анимированный алерт «Сбор начался» при старте и
  крупный алерт «Победитель: …» с фанфарами при остановке колеса.

### Fixed
- **DonationAlerts**: стабилизировано Centrifugo WebSocket-подключение —
  авто-реконнект с бэкоффом, heartbeat (ping/pong watchdog) и автоматическое
  обновление `access_token` через `refresh_token`.
- **Twitch EventSub**: добавлены keepalive-watchdog, авто-refresh токена и
  исправлен двойной реконнект при `session_reconnect`.
- Детальное логирование событий подключения/ошибок для интеграций.

### Changed
- **Оптимизация Electron**: ограничение FPS для фоновых окон,
  `backgroundThrottling`/`spellcheck` и очистка ресурсов при выходе.
- Раскладка оверлея перенесена в локальную БД (единый источник истины),
  из `config.json` убрано дублирование.
- Токены авторизации больше не хранятся в открытом виде в `config.json`.

### Security
- **Безопасное хранилище ключей**: секреты Twitch/DonationAlerts шифруются
  через Electron `safeStorage` (DPAPI/Keychain/libsecret) перед записью на диск.

## [1.7.0] — 2026-08-09

### Added
- Отдельное окно **«Чат»** — читаемый лог сообщений Twitch-чата (без
  прозрачных карточек оверлея), чтобы следить за чатом во время стрима, не
  переключаясь в браузер. Открывается кнопкой в топбаре панели управления.
  Только чтение — отправка сообщений не поддерживается (чат подключён
  анонимно). Не хранит историю: показывает сообщения, пришедшие пока окно
  открыто, как и виджет чата на оверлее.
- Всплывающее окно **редактора кода** для «Своего виджета» — вкладки
  HTML / CSS / JS с живым превью (обновляется на лету при вводе) и кнопкой
  «Сохранить». Открывается кнопкой «Редактировать код» в панели свойств,
  когда у виджета выбран режим «Свой HTML».

### Fixed
- **JS в «Своём виджете» теперь реально выполняется.** Раньше произвольный
  HTML вставлялся через `innerHTML`, из-за чего вложенные `<script>` тихо
  не срабатывали (стандартное поведение браузеров). Рендер переведён на
  `<iframe>` с полноценным HTML-документом (свой `<style>` и `<script>`),
  так что таймеры, анимации и любой код в виджете работают по-настоящему —
  и в превью редактора, и на настоящем оверлее.
