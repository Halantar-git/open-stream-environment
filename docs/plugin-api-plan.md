# API виджетов и тем — план

Черновик от 20.10.2026. Ничего не реализовано: это план открытого API для
кастомных виджетов и тем и заказов на них. Магазин и платежи сюда не входят —
на старте API остаётся свободным, а деньги приходят за работу.

## Принципы

- API открыт и стабилен; продаётся работа, а не доступ к API.
- Ядро остаётся GPL; заказной код отдаём под свободной лицензией.
- Пакеты не линкуются в бинарник: папка/zip в пользовательских данных.
- Новые фоны и анимации — только по бюджету производительности, статика по
  умолчанию.
- Обратная совместимость через `apiVersion` и semver.

## Архитектурные решения

Зафиксировать до кода:

- Публичный namespace `window.OSE`: `OSE.defineWidget`, `OSE.BaseWidget`,
  `t`, `asset`, `readCssVar`, `subscribe`, `send`.
- Два типа пакетов: `widget.json` + код и `theme.json` + токены/CSS/ассеты.
- Пакеты лежат в `%APPDATA%/com.openstreamenvironment.app/plugins/<id>/`,
  сервер отдаёт `/plugins/<id>/`.
- Настройки виджета описываются схемой (string, bool, color, range, select,
  media, html) — инспектор рисуется автоматически.
- Темы: токены + CSS в области `[data-theme="<id>"]`, локальные шрифты и
  картинки, обязательный файл лицензии на шрифты.
- `apiVersion: 1`, `minAppVersion`, проверка манифеста и ошибки без падения
  оверлея.
- Sandbox — отдельным этапом; до него ставим только доверенные пакеты с явным
  предупреждением.

## Этапы

| Этап | Что делаем | Результат | Оценка |
|---|---|---|---|
| **0. Спецификация** | API виджета и темы, формат манифеста, схема настроек, пакеты, лицензии, правила совместимости | `docs/plugin-api.md`, `docs/theme-api.md`, скелет шаблона | 3–5 дней |
| **1. Виджет-API MVP** | Загрузчик из `plugins/`, регистрация в каталоге, публичный `OSE`, схема → инспектор, ассеты, локализация, hot reload, пример | Сторонний виджет ставится папкой, появляется в библиотеке, настройки и события работают | 1.5–2 недели |
| **2. Тема-API MVP** | Пакет темы, токены/CSS, шрифты/ассеты, установка/удаление, превью, экспорт/импорт, валидация | Тема ставится пакетом, применяется на оверлее, сценах и заставке, экспортируется | 1–1.5 недели |
| **3. Упаковка и доставка** | Zip, версии, контрольные суммы/подпись, установка из файла, проверка обновлений, статусы ошибок | Клиенту можно отдать один файл, обновление не ломает установку | 3–5 дней |
| **4. Sandbox и права** | iframe-рантайм, `postMessage`-RPC, права (события/медиа/сеть), лимиты FPS/CPU | Можно безопасно ставить чужие пакеты | 2–3 недели |
| **5. Заказы** | Портфолио (2 темы + 1 виджет бесплатно), страница «заказать», прайс, договор/лицензия, поддержка | Первый платный заказ и обратная связь в API | параллельно |
| **6. Магазин/лицензии** | Внешний checkout, лицензионные ключи, обновления; маркетплейс — позже | — | только при спросе |

Порядок: **0 → 1 → 2 → 3 → первые заказы → 4 → 6.** Sandbox можно отложить,
если на старте ставите только свои и доверенные пакеты; но до публикации чужих
он обязателен.

## MVP виджета

- `widget.json`: id, имя, версия, автор, entry, styles, assets,
  defaultGeometry, minW/minH, renderType, config schema, capabilities.
- `OSE.defineWidget(id, class extends OSE.BaseWidget)` с
  `onMount/render/onUpdate/unmount/resize`.
- Контекст: `this.config`, `this.geometry`, `this.element/canvas/ctx`,
  `this.t()`, `this.asset()`, `this.readCssVar()`, `this.subscribe()`,
  `this.send()`, `this.later/every`.
- Каталог: карточка, иконка, описание, категория.
- Инспектор по схеме; для сложных случаев — необязательный кастомный HTML.
- Установка/удаление/включение/выключение, hot reload в dev-режиме.
- Пример: простой виджет с настройкой текста/цвета/размера и подпиской на
  донаты.

## MVP темы

- `theme.json`: id, имя, версия, токены, CSS, шрифты, ассеты,
  `threeDWidgets`, превью.
- Применение токенов и CSS на всех страницах, скоуп, чтобы не течь в другие
  темы.
- Проверка обязательных `--md-*` и контраста; предупреждения, а не падение.
- Шрифты: файл + лицензия, только разрешённые к коммерческому использованию.
- Экспорт/импорт zip, превью, удаление без следов.

## Бизнес-часть

- Сделать 2 бесплатные темы и 1 виджет как портфолио и демо API.
- Страница «Заказать»: что входит, сроки, цена, что нужно от клиента,
  лицензия на результат.
- Прайс: фиксированные пакеты (тема / виджет / внедрение) + почасовая.
- Правило: исходники отдаём под свободной лицензией, оплата — за работу,
  поддержку и сроки.
- Поддержка: бесплатные багфиксы 30 дней, дальше — подписка или почасовая.

## Проверки и качество

- Юнит-тесты: валидация манифеста, загрузчик, схема → инспектор, пакет темы.
- Интеграция: пример-виджет в оверлее и на сцене, скриншот в OBS, отсутствие
  ошибок в консоли.
- Бюджет производительности: статичный фон, лимит FPS для canvas, проверка
  через `document.hidden`.
- Гейт: `npm test`, `npm run lint`, при изменениях Rust — `cargo test`,
  `cargo clippy`, `cargo fmt --check`.

## Риски

- API придётся менять после первых заказов — лечится `apiVersion` и тестом
  совместимости.
- Sandbox сложнее, чем кажется; не смешивать его с MVP, иначе заказы не
  начнутся.
- GPL и заказной код: по умолчанию свободная лицензия; если клиент хочет
  закрытый код — отдельное решение и юридическая проверка.
- Поддержка съедает время: фиксировать объём и сроки в договоре.
- Производительность: без бюджета один заказной виджет может уронить эфир.

## Открытые вопросы

1. Ставим ли на старте только доверенные пакеты или сразу делаем sandbox?
2. Виджетам нужен WebGL/canvas или достаточно DOM?
3. Темам нужны свои фоны/картинки или только цвета, шрифты и CSS?
4. Заказной код — по умолчанию GPL/свободная лицензия?
5. Цена: фиксированные пакеты или почасовая?
