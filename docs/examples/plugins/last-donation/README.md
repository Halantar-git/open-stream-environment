# Последний донат

Пример пакетного виджета для Open Stream Environment: карточка с последним
донатом, настройками и подпиской на событие `ALERT`.

## Что показывает

- заголовок из настроек;
- сумму последнего доната в валюте события;
- ник донатера и сообщение (если тумблер включён);
- «Ждём донат», пока событий не было.

Виджет обновляется и на настоящем донате, и на тестовом алерте из панели —
удобно проверять, не дожидаясь зрителя.

## Настройки

| Ключ | Тип | По умолчанию |
|---|---|---|
| `title` | строка | «Последний донат» |
| `amountSize` | ползунок 16–72 | 36 |
| `accent` | цвет | `#7ee0d6` |
| `showMessage` | тумблер | включён |

Цвет суммы берётся из настройки, а если поле очистить — из токена темы
`--md-primary`; остальные цвета тоже приходят из активной темы.

## Установка

Скопируйте папку `last-donation` в каталог пакетов и перезапустите OSE:

- разработка (`npm run tauri:dev`) — `config/plugins/`;
- установленное приложение — `%APPDATA%\com.openstreamenvironment.app\plugins\`.

Проверка: `npx ose-plugin check .`.

## Что смотреть в коде

- `widget.json` — схема настроек, которую инспектор рисует сам;
- `widget.js` — `onMount` подписывается на `OSE.EVENT_TYPES.ALERT`, а
  `render` пересобирает карточку через `textContent` — текст пользователя не
  становится разметкой;
- `widget.css` — стили ограничены `[data-type="plugin:last-donation"]`, чтобы не
  задеть встроенные виджеты.
